# Mkeka Betting

Tovuti ya mkekabetting.com: mkeka wa leo, code za mikeka, kikokotoo cha mkeka, matokeo na takwimu, kampuni bora za kubeti (pamoja na promo code), miongozo na sehemu ya kucheza kwa kiasi (18+).

Tovuti yote iko kwenye faili moja: `index.html` (HTML, CSS na JavaScript ndani yake, nembo zimewekwa kama picha za ndani).

## Kusasisha kila siku

Fungua `index.html` na utafute sehemu ya `/* ===== DATA: badilisha hapa ===== */` kwenye `<script>`:

| Unachotaka kubadilisha | Tafuta |
|---|---|
| Tarehe ya mkeka (hero na kadi za code) | `MKEKA_DATE` |
| Tips za Leo / Kesho | `TIPS` |
| Code za mikeka na kampuni ya Mkeka wa Siku | `CODES` |
| Kampuni Bora kwa Sasa na pop-up | `MONTH_PICK` |
| Kampuni, viungo vya affiliate, promo code, ofa | `BOOKS` |
| Matokeo ya tips | `RESULTS` |
| Matokeo ya mikeka ya code | `PAST_SLIPS` |

Viungo vya Instagram na WhatsApp: tafuta `#instagram` na `#whatsapp` kwenye HTML.

## Kuiweka hewani

- **GitHub Pages:** Settings → Pages → Source: "Deploy from a branch" → branch `main`, folder `/ (root)`.
- **Hosting nyingine (mf. Hostinger):** pakia `index.html` kwenye folda ya `public_html`.
